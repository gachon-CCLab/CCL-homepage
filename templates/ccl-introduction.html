About the Lab

01 / OVERVIEW

Led by Professor KangYoon Lee in Gachon University's Department of Computer Engineering, CCL studies real-world challenges with AI, cognitive computing, IoT and cloud technologies.

Our FedOps platform connects model training and operations in distributed environments. We study post-TAVR complication and psychiatric risk prediction, alongside industry collaborations and national research projects.

Federated AI AgentOps

From local data
to federated AI agents.

Train models together while keeping raw data on participants' devices. Use the trained models to build, run and improve AI agents.

  2. 02 / COLLABORATEFederated learningJoin a Task

  3. 03 / VERSIONModel versionsGlobal Model
    Version and lineage tracking
  4. 04 / BUILD & USEAgent useBuild · Test
    Local Chat · Serving

Web · Registry coordinates Tasks, participation and model versions. Agent Studio supports local development and execution. FL Server aggregates model updates.

Raw data stays local. Each Agent Build pins a selected model version. After validation, a new model can be used in a new Agent Revision.
